# Correspondances V3

Cette version met à jour l’accueil, la page Fonctions et la page Vision.

La navigation devient un îlot flottant. Sur ordinateur, elle se replie après la sortie du pointeur et se déploie au survol ou au clavier. Sur mobile, le bouton ouvre le menu.

Les trois points de chargement rebondissent dans le héros. Les couleurs reprennent la palette du logo avec le bleu nuit, le bleu, le rose corail et le vert citron.

Pour déployer, remplacez le contenu de votre dépôt par les fichiers de ce dossier, faites un commit puis poussez sur GitHub. Vercel publiera le changement si le dépôt est relié au projet.
